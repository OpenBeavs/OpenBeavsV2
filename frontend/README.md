# OpenBeavs frontend

Run `npm ci`, then start the whole stack with the launcher in the
[root README](../README.md), or run `npm run dev` with `BACKEND_ORIGIN` set to the
address of a running v2 backend (the launcher uses `http://127.0.0.1:8010`).

See [frontend setup and integration](../docs/frontend.md) for backend setup,
configuration, supported behavior, checks, deployment requirements, and notices.
